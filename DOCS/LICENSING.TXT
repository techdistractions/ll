REVIEWED THIRD-PARTY BOUNDARIES
- DOS3.H is adapted from EtherDFS-3. It retains Mateusz Viste's and Frank
  Haeseler's copyright notices. The upstream application carries an MIT
  permission notice, reproduced in LICENSES\ETHERDFS.TXT. Its original source:
  https://github.com/CryptusDE/EtherDFS-3
- The upstream Watcom-derived CHINT086.ASM is reference-only. It is absent
  from the Lite Link source, build inputs and linked objects. FSHOOK.ASM is
  Lite Link's own interrupt hook implementation.
- The 3Com backend is documented as independently implemented from the 3Com
  hardware reference. No Crynwr packet-driver implementation is included.
- The NE2000/TCP foundation derives from the maintainer's NowBasic/NETLAB
  project. Its provenance is not represented as an external GPL grant.
- No separate GPL-only third-party implementation was identified in the
  distributed source/build inputs. This is a bounded source/build audit,
  not a guarantee about unknown or undisclosed ownership claims.

COMPILER RUNTIME
The build uses Open Watcom. Link maps show unmodified arithmetic helper code
in LLGet/LLTime/LLNIC/NETDIAG, and standard C startup/runtime in the optional
LLRWTEST verifier. These parts keep their upstream license and copyrights;
they are not part of the public-domain dedication. A full license copy,
source URL and executable-embedded availability notice are supplied. No
compiler or runtime source has been modified or relicensed. See THIRDPARTY.TXT.
LLFS uses no linked C-runtime module, so its resident allocation is unaffected
by the added notices. Windows uses the configured system DLL imports.
